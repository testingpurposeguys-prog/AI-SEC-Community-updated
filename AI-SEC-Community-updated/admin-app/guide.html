How to use the admin dashboard

Code touch pannama website content-a neengale update pannalam. Open dashboard

0. Live preview

  • Editor-la right side-la Live preview theriyum. Type pannum bodhe website epdi irukkum-nu update aagum.
  • Mela irukkura Dark / Light and Desktop / Tablet / Mobile buttons use panni check pannalam.
  • Yellow ⚠ notes: thappa link, extra meetup maari problems-a Publish-ku munnadi katum.

1. Epdi live aagum

  1. Dashboard-la edit pannunga.
  2. Publish → Publish now click pannunga.
  3. 1 to 2 nimisham-la website-la live-a theriyum. Theriyala-na Ctrl+Shift+R pannunga.

2. Monthly meetup update add panna

  1. Left-la Monthly Updates → Monthly Updates click.
  2. Add monthly meetups + click.
  3. Month (any date in that month), host, summary, group photo fill pannunga.
  4. Session speakers, panel, flash mentors: ovvonnaiyum Add + panni name, photo, LinkedIn, topic podunga.
  5. Publish. Past Events page-la top-la newest-a varum.

3. Upcoming meetup (Home page)

  1. Upcoming Meetups → Add. Chapter select pannunga (Bangalore / Hyderabad / Chennai).
  2. Title, date text, venue, banner, Luma link podunga. Publish.
  3. Oru chapter-ku oru entry mattum. Meetup mudinjathum entry-a delete pannunga, TBA card thirumba varum.

4. Community partners

  1. Community Partners → Add partners +. Name, logo, description, website podunga.
  2. Order maatha: row-a drag pannunga. Remove panna: X click.

5. Site Settings (ellaa pages-kum)

  • Register Now link: top bar button-oda Luma link, ellaa pages-lum maarum.
  • Announcement bar: "Show the bar?" on pannina ellaa pages-kum top-la purple bar varum. Off pannina maraiyum.
  • Social links: footer LinkedIn, YouTube, WhatsApp, X icons-ku links.
  • Home page numbers: 230+, 60+, 8000+ maari 3 boxes.

6. Photos

  • Image field-la Choose an image → Upload. Pazhaya photo-va Media tab-la paakkalaam.
  • 500 KB-ku keela compress pannunga (squoosh.app). Speaker photos 400×400 pothum.
  • File name-la space vendaam: ranjith-singh.jpg.
  • Right-side Live preview-la photo, text ellam neenga type panna-pa-ve update aagum. Pazhaya photos theriya cms/index.html-la site URL set pannanum.

7. Edhu innum dashboard-la illa

Ivai innum HTML-la irukku, developer thaan maatha mudiyum: January–October 2026 pazhaya months, About page, Chapters, Hackathon, Virtual Meetups, Get Involved, forms (inquiry forms, login, register).

8. Problem vandha

  • Login aagala: GitHub repo-la unga account-ku write access irukka paarunga. Popup block aagi irukkalam.
  • Publish panninum site maarala: 2 nimisham wait pannunga, Ctrl+Shift+R. Appavum illa-na Vercel → Deployments-la error irukka paarunga.
  • Thappa edit panniten: GitHub repo → History-la pazhaya version-ku revert pannalam.
